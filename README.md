# حصن المسلم — أذكار الصباح والمساء والنوم والاستيقاظ

موقع ثابت (ملف `index.html` واحد) يعرض الأذكار الصحيحة بمصادرها مع مسبحة إلكترونية، بحث، مفضلة، تذكير يومي، وثيم ليلي/نهاري.

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى مستودع `Public` بحيث يكون `index.html` في الجذر.
2. من `Settings` ثم `Pages`: المصدر `Deploy from a branch`، الفرع `main`، المجلد `/ (root)`.
3. الرابط سيكون: `https://USERNAME.github.io/REPO/`

## النسخ المرجعية (Snapshots)

كل تغيير يُحفظ تلقائيا كـ commit في Git برسالة توضّح ما تم وأُضيف له تاريخ التغيير، ويمكن الرجوع لأي نسخة سابقة بـ `git revert <commit>` أو `git checkout <commit>`.

### مسارات المُوجِّه

| المسار | الصفحة |
|---|---|
| `#/` | الرئيسية: بطاقة المواقيت + النوافذ الست + ركن الأطفال |
| `#/s/<cat>` | قسم كامل ببطاقات الأذكار (`sabahmasa` مع تبويب صباح/مساء، `sleep`، `wake`، `salah`، `others`، `duas`) |
| `#/s/others` | قائمة منسدلة بكل الأذكار الأخرى، والضغط على ذكر يفتح صفحة مستقلة به |
| `#/d/<i>` | صفحة ذكر واحد |
| `#/kids` و `#/kids/<grp>/<i>` | ركن الأطفال ثم النافذة ثم الذكر |
| `#/duas` | الأدعية المصوّرة (50 صفحة) مع تصفّح وطباعة/حفظ PDF |
| `#/q/<نص>` | نتائج البحث |

### أوامر مهمة

```bash
# عرض كل النسخ المعنونة
git tag -l

# الرجوع المؤقت لعرض نسخة قديمة
git checkout snapshot-2026-10-17

# استرجاع نسخة مرجعية كأحدث نسخة (مع الإبقاء على التاريخ)
git revert <commit>

# إنشاء نسخة مرجعية جديدة بعد أي تغيير
git tag -a snapshot-YYYY-MM-DD -m "وصف التغيير والتاريخ"
```

### العادة المتبعة

عند أي تغيير مستقبلي:
1. يُحفظ التعديل كـ commit برسالة عربية توضّح التغيير.
2. يُرفق التعليق: ماذا تغيّر، وسببه، وتاريخ التغيير.
3. عند حدوث مشكلة غير مرغوبة: `git revert <commit>` يُرجع الوضع السابق ويُبقي السجل.
4. يُنشئ Tag معنون للنسخة المستقرة بعد كل إصلاح مهم.
